三語作品展示網站：繁體中文（預設）、English、日本語。每頁右上角可切換語言並保留所在作品頁。
已移除售價、庫存、購買詢問按鈕與 Email 聯絡區。

## 上傳 GitHub Pages

1. 建立新的公開 Repository：建議 shogi-gallery-fb，與原本販售版分開。
2. 將本資料夾內全部檔案與資料夾上傳到 Repository 根目錄，保留 assets、zh、en、ja。
3. Settings → Pages → Deploy from a branch → main → /(root) → Save。
4. 發布後網址通常為 https://alexlin927.github.io/shogi-gallery-fb/ 。請將這個網站連結貼到 FB 貼文。
5. 直接分享中文 zh/index.html、英文 en/index.html 或日文 ja/index.html 的網址也可以。

Facebook 貼文本身不能內嵌這個語言選單；朋友點開網站連結後即可選語言。
已加入分享標題與簡介。Facebook 是否顯示縮圖由其抓取結果決定；本包未設定需要正式網址的絕對分享圖片路徑。

本機預覽：打開 index.html 或 zh/index.html。
